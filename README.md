# military-countdown

開啟 `index.html` 即可查看依台北日期顯示的退伍倒數。

畫面最下方的「◀前一天／後一天▶」可切換 2026/10/26 至 2026/10/30
的每日小語、任務與退伍畫面。未到的日期依台北時間鎖定，
按鈕會顯示半透明虛線的「不能偷看！」，到當天後自動開放。
第一天無法再往前，退伍日無法再往後；重新開啟頁面會顯示今天。

各日期的任務簽收分別儲存在瀏覽器，重新查看時仍會顯示固定回覆：

- 倒數 5 天：今天也辛苦了♡
- 倒數 4 天：小毛已收到你的簽收🫡
- 倒數 3 天：再一下下就回來啦！
- 倒數 2 天：今天也有多想你一點點哦💖

日期鎖定是前端互動限制，並非保密機制；每日內容仍包含在 HTML 原始碼中。
