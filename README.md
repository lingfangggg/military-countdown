# 退伍倒數 🪖

把「還有幾天呀」變成每天都想點開的小小期待

一個送給葉先生的倒數網頁，陪你一天一天，慢慢靠近回來的日子✨

## 💌 從這裡打開

**[點這裡，離見面更進一步💖](https://lingfangggg.github.io/military-countdown/)**

手機、電腦都可以開，不用安裝，也不用登入


## 🌷 小小使用說明

- 網頁會依台北日期，準備好當天的畫面📆
- 想回頭看看，可以用畫面最下方的日期按鈕🕹️
- 還沒到的日子就先乖乖等，驚喜要當天打開才剛剛好😌
- 簽收紀錄會留在目前的瀏覽器；換裝置或清除網站資料，就不會跟著搬家囉🤲🏻


##  🔒 不暴雷約定

這裡不寫每天藏了什麼，也不提前公布最後的畫面

請把好奇心留給每天的自己，一天拆一點點就好
